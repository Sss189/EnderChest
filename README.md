# Pocket Ender Chest Command

## 中文

这是一个 Minecraft 1.12.2 模组，玩家可以使用 `/enderchest` 指令随时打开自己的末影箱，并使用 `/worldchest` 打开跨存档共享的九格个人世界箱。管理员可以按维度分别启用或禁用这两类指令，也可以要求玩家先完成指定进度才能使用。

将项目导入 IntelliJ IDEA，并使用 Java 25 运行 `gradlew build`；构建完成的模组文件位于 `build/libs`。

### 依赖

- 无额外必需依赖

## English

This Minecraft 1.12.2 mod lets players open their Ender Chest anywhere with `/enderchest`, and access a nine-slot personal World Chest shared across world saves with `/worldchest`. Administrators can enable or disable each command by dimension and require players to complete a specified advancement before using it.

Import the project into IntelliJ IDEA and run `gradlew build` with Java 25; the built mod file will be located in `build/libs`.

### Dependencies

- No additional required dependencies
